# Frequently Asked Questions: Scalable URL Shortener & Analytics

### 1. What is Scalable URL Shortener & Analytics?
URL shortening and click redirection service with MongoDB Atlas analytics, QR codes, and custom slugs.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), Vanilla JS / TailwindCSS.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/31-url-shortener/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
