# Technical Glossary

- **Nanoid**: A small, secure, URL-friendly unique string ID generator utilizing cryptographic random values.
- **Base62**: An encoding scheme using 62 alphanumeric characters (`0-9`, `a-z`, `A-Z`) commonly used in link shortening.
- **HTTP 302 Found**: A common status code indicating that the resource resides temporarily under a different URI.
- **DAO (Data Access Object)**: A structural design pattern that abstracts and encapsulates all access to the data source.
- **Atomic Operation**: An operation that completes in a single step relative to other threads/processes, preventing race conditions.
