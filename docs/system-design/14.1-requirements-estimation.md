# 14.1 Requirements & Capacity Estimation

- **DAU**: 10 million active users
- **New URLs / Month**: 100 million
- **Read/Write Ratio**: 100:1 (Read heavy)
- **Write QPS**: ~40 URLs/sec
- **Read QPS**: ~4,000 redirects/sec (Peak ~12,000 QPS)
- **Storage**: ~500 bytes per URL record * 100M = 50GB / month, ~3TB over 5 years.
